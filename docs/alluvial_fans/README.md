# מניפות סחף (GLO-30)
סריקה ארצית ברזולוציה של כ-30 מ׳ על Copernicus DEM GLO-30 (AWS Open Data). אימות מול 13 מניפות ידועות: 13/13 ראש וטביעה. תמונות Sentinel-2 שימשו לבדיקה פנימית בלבד ולא נכנסו לריפו או לאתר. מפות המכון הגאולוגי לא שומשו ולא ישמשו.

לאחר סינון שטח וחפיפה נשארו 186 מניפות, מתוכן 78 סומנו `review` והוסתרו: הן אינן בשכבת האתר (`site/data/fans.geojson`) ואינן מקבלות דגל או טווח הגעה במנוע. הן שמורות ב-`data/alluvial_fans_review/` לסקירה פנימית בלבד. בשכבה המפורסמת: 108 מניפות (כולן במדבר, כולל 13 הידועות).

המנוע מוסיף דגל «התפשטות אפשרית» וטווח הגעה למקטעים בשכבה המפורסמת בלבד. אין שינוי ב-calibration, בספים או במערכי ההסתברות.
