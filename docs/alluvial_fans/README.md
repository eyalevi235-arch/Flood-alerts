# מניפות סחף (GLO-30)
סריקה ארצית ברזולוציה של כ-30 מ׳ על Copernicus DEM GLO-30 (AWS Open Data, בלי הרשמה). אימות מול 13 מניפות ידועות: 13/13 ראש וטביעה. תמונות Sentinel-2 שימשו לבדיקה פנימית בלבד ולא נכנסו לריפו או לאתר. מפות המכון הגאולוגי לא שומשו (ראו GSI_LICENCE.md).

סינון אחרי הסריקה: שטח טביעה מינימלי 0.15 קמ״ר (למעט הידועות), והסרת חפיפה מעל 40% מהקטנה. 78 מניפות מסומנות review (צפון/מרכז, אורך מעל 6.5 ק״מ, או טביעה מעל 40 קמ״ר) – מומלץ להציג אותן כשכבת בדיקה.

המנוע מוסיף דגל «התפשטות אפשרית» וטווח הגעה. אין שינוי ב-calibration, בספים או במערכי ההסתברות.
